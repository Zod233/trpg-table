# 角色卡库

- 一个角色一个文件夹：`characters/<角色id>/角色卡.md`，角色 id 用英文短名。
- 这里只放**审核通过**的卡；卡头必须写 `规则系统`、`系统版本`、`生成方式`、`审核状态`。
- 开团时复制到 `sessions/<本次>/01-车卡/`，本团的伤害与成长只改副本。
- **跨系统不复用**：COC 的卡不能直接进 D&D 团，必须按目标系统的 `车卡规格.md` 重车。
- 同一张卡可以带多个团，各团经历互不可见。

## 强度标注（写在卡头版本行后一行）

`强度：常规 / 偏强 / 偏弱` —— 由审核时按创建期上限判断，用于同桌混搭时保持差不多的量级。
