# 第一次用：从零到开口说第一句话

README 讲的是「它是什么、为什么值得用」。这里只讲一件事：**你现在手上有这个仓库，怎么在半小时内真的开一场团。**

照着做，不要跳步。每一步后面都写了「你应该看到什么」——没看到，就是那一步没成，别往下走。

---

## 第 0 步：你要准备的三样东西

| 要什么 | 具体 | 为什么 |
| --- | --- | --- |
| Python | 3.10 以上（实测 3.13）。命令行敲 `python --version` 能看到版本号即可 | 所有工具脚本都是 Python 写的，不装跑不动 |
| 豆包桌面端 | 能打开一个**本地文件夹**的版本 | KP 的脑子是模型，这个文件夹是它的记忆 |
| 一个空文件夹 | 建议放在 `D:\` 这类短路径下，别放桌面、别放带中文和空格的深层目录 | Windows 下长路径 + 中文会让脚本报「找不到路径」 |

不需要装的东西：不用买 API key，不用装数据库，不用 Docker。

> `pypdf` 只有在你**要把 PDF 模组转成本仓库格式**时才需要（`pip install pypdf`）。只想跑 `rain-train`，不用装。

---

## 第 1 步：进到仓库根目录

打开 PowerShell，进到仓库根：

```powershell
cd "D:\WorkSpace\IdeaLab\跑团"
```

**你应该看到**：命令提示符正常返回，没有红字。之后所有命令都在这个目录下执行——换目录是最高频的失败原因。

---

## 第 2 步：生成一场会话

```powershell
python tools/new_session.py --scenario rain-train --system coc7 `
  --persona 老派说书人 --characters lin-yan --rating L1 --dice KP自掷
```

**你应该看到**：

```
已生成：...\sessions\2026-11-24-rain-train-01
  剧本：rain-train  系统：coc7 v1.0  人设：老派说书人  分级：L1
  角色：1 张（lin-yan）
```

各行含义：`--scenario` 是要跑的本（对应 `scenarios/<id>/`），`--system` 是规则包，`--persona` 是 KP 说话风格，`--characters` 是参团角色，`--rating L1` 是内容分级，`--dice` 是骰值来源。跑商业模组时再加 `--local`，会话会进 `sessions/local/`（不进仓库）。

---

## 第 3 步：开局前体检

```powershell
python tools/check_session.py "sessions\2026-11-24-rain-train-01"
```

**你应该看到最后两行**：

```
通过 8 项，提醒 1 项，失败 0 项。
结论：可以开局。
```

只要出现「失败」，就停下来按提示改，别硬开——这一步查的就是装载清单断链、角色卡没过审、日志缺失。

---

## 第 4 步：打包成「模型能看见的最小包」

```powershell
python tools/pack_session.py "sessions\2026-11-24-rain-train-01"
```

**你应该看到**：

```
已打包：...\dist\2026-11-24-rain-train-01
  文件 27 个，入口 START.md
```

这一步是关键，别嫌麻烦：它把这一场真正需要的文件复制出来，**模型只看这个文件夹，看不到 `scenarios/local/` 里的商业模组原文，也看不到别的会话**。直接让模型读整个仓库，既浪费上下文，也会串场。

---

## 第 5 步：让豆包打开这个包，然后说这句话

在豆包里把 `dist\2026-11-24-rain-train-01` 这个文件夹挂上（作为工作目录，或直接把文件夹拖进对话），然后发这句：

> 读 START.md，按里面的顺序装载，装载完先告诉我你读到了什么。我要自己车卡，先别替我定人设。

**你应该看到**：它复述装载结果（读了哪几个文件、这一场是什么本、骰源是什么），然后进入车卡。

如果它直接开始讲故事、或者替你安排好了一个角色——**打断它**，说「回到车卡」。这一步跳过去，整场的代入感就没了，这是最常见的翻车方式。

---

## 第 6 步：跑起来之后，你只需要会三句话

| 你想干什么 | 就这么说 |
| --- | --- |
| 我想做某件事 | 「我要……」+ 具体动作。别问「我能吗」，直接说你要做什么，KP 来判断要不要判定 |
| 我要用某技能 | 「我过一个侦查」——可以主动申请，但**判定权在 KP**，它可以说这个不需要掷 |
| 我不满意这个裁定 | 「这条规则依据是什么」→ 它必须给出处。规则可以吵，**已经掷出来的骰值不能吵** |

三条红线，碰到了就是框架出问题，不是你的问题：
1. 它让你自己报骰值数字 → 不行，只接受 `tools/roll.py` 的输出或 KP 亲掷
2. 它把你的主线事实记错（谁欠你钱、门从哪边闩） → 这是漂移，让它去对 `状态跟踪.md`
3. 它在你明确说「停」之后还继续推进 → 直接喊停

---

## 第 7 步：今天就到这儿，怎么收

关掉对话就行，**不需要一次跑完**。回来时重新打开同一个包，说：

> 读 状态跟踪 和最新一份日志，我们接着来。

它靠 `前情提要.md` + `状态跟踪.md` + 最新日志接上，不依赖聊天记录——所以关窗口、换天、隔一周都接得上。

一场真跑完了，说一句「结算」，让它做三件事：写当天日志（含检定表）、更新状态跟踪、把成长落到角色卡上。然后你回到仓库根，跑：

```powershell
python tools/check_drift.py "sessions\2026-11-24-rain-train-01"
```

**你应该看到**：`0 漂移`。有漂移就按提示补日志。

---

## 卡住了，先对这几条

| 现象 | 多半是 |
| --- | --- |
| `找不到会话文件夹` | 当前目录不在仓库根，或路径少了引号。Windows 路径有空格必须加 `"` |
| `剧本 id 不存在` | `--scenario` 写的是 `scenarios/` 下的目录名；商业模组要加 `--local` 且目录在 `scenarios/local/` 下 |
| `check_session` 报装载清单断链 | manifest 里写的某个文件被删了或改了名，回去改 `00-本次设定.md` 的装载清单 |
| 模型说「我看不到某个文件」 | 那个文件没进最小包。它不在装载清单里，或路径写错；先 `pack_session` 重新打 |
| 跑着跑着它开始瞎编线索 | 剧本六件没读完就开场。让它「重读 session/02-剧本」，别顺着编 |

---

## 换成你自己的本

`rain-train` 只是样板。你要跑自己的故事，按 `docs/模组接入指南.md` 把本拆成六件骨架（概览、背景与真相、登场人物、线索与调查点、关键场景、结局分支），再补一节「车卡约束」。

商业模组记住两件事：原文放 `scenarios/local/<id>/`（已在 `.gitignore` 里，不会被误传），会话加 `--local`。
