# 内容边界与版权

## 一、内容分级

| 级别 | 允许 | 禁止 |
| --- | --- | --- |
| L0 | 谜题、日常、轻度冲突 | 任何血腥、恐怖、死亡描写 |
| L1 | 恐怖氛围、尸体与血迹（不写细节）、威胁与追逃 | 详细解剖、酷刑、对儿童的伤害 |
| L2 | 明确暴力、酷刑、精神崩溃过程 | 性描写、性暴力 |
| L3 | 成人向情节，仅限全员成年并明确同意 | 未成年相关的一切 |

默认 L1。有未成年参与者时不得高于 L1，升至 L2 需全体同意并写进 manifest。L3 不进公开仓库的任何剧本。

## 二、桌上机制

1. **喊停（X 卡）**：任何参与者可随时喊停，不需要理由。KP 立即切换叙述、跳过该段，不追问、不记账、不改判定。
2. **内容预告**：开局前用 3 句话说明本团的级别、可能出现的元素，允许玩家提出不宜内容。
3. **事后处理**：出现越界内容，当场切断，记入 `04-KP私有.md` 的复盘栏，下一场调整；不做公开争论。

## 三、仓库放什么

| 可以进仓库 | 不可以进仓库 |
| --- | --- |
| 自己写的剧本 | 下载来的商业模组、同人翻译、未授权搬运 |
| 自己写的角色卡 | 他人未授权的角色与美术 |
| 规则摘要与自订团规 | 规则书原文的整段复制 |
| 自绘示意图 | 商业插画、官方地图 |

第三方模组放在本地 `scenarios/local/` 或私有目录，`.gitignore` 已排除，不进版本库。

## 四、规则系统的引用

- **D&D 5.1 SRD** 已按 CC-BY-4.0 开放，可引用其中内容，需保留署名与许可声明。
- **COC 第 7 版** 规则书未开放授权：本仓库的 `systems/coc7/` 只写判定摘要与本框架自订团规，不复刻原文；商业使用需自行遵循 Chaosium 的政策。
- 规则系统的名称用于指称兼容性，不表示官方认可或授权。

## 五、许可

本仓库内容以 MIT 发布。第三方模组、规则原文、美术素材不适用本许可，也不在本仓库内。

## 六、剧本来源自查

接入外部模组前回答三个问题，任一答案不利就不要进仓库：

1. 这份模组的再分发是否被明确允许（作者声明、CC 许可、官方开放内容）？
2. 是否包含他人的原创美术、地图或大段原文？
3. 改写后的骨架是否已经脱离原文、成为独立作品？
