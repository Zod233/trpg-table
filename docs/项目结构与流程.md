## 开团流程

1. **放剧本**：按 `docs/模组接入指南.md` 把外部模组改写成 `scenarios/<id>/` 的六件骨架，声明 `规则系统`、`系统版本`、`形态`、`内容分级`。
2. **定系统与人设**：确认 `systems/<系统id>/` 版本可用；按氛围选 `keeper/personas/` 中的人设。
3. **车卡**：新人用 `keeper/roles/车卡向导.md` 一格格填；派生值当场算。
4. **审核**：按 `systems/<系统>/车卡规格.md` 过数值与叙事两关；未过审不得进场。
5. **建会话**：`python tools/new_session.py --scenario <id> --system coc7 --persona <人设> --characters <角色id>`。
6. **预检**：`python tools/check_session.py "sessions/<会话>"`，有失败项先修。
7. **开局**：按 `keeper/system-prompt.md` 的装载顺序组上下文，从环境落地开始。
8. **逐场**：写 `03-日志/日志-00N.md`，更新 `状态跟踪.md` 与 `前情提要.md`；暗投与判例进 `04-KP私有.md`。
9. **复盘**：`python tools/export_stats.py sessions --out stats.csv`。

## 收场流程

- 会话文件夹原样保留，`00-本次设定.md` 的 `状态` 改为「已结团」。
- 值得复用的 NPC、桥段、修正过的线索合并回 `scenarios/` 母本，概览版本号加一位。
- 跨团复用的角色成长回流 `characters/`。
- 判例里被复核修订过的条目，判断该改 `_framework.md` 还是规则包。

## 内容分层规则

- 玩家可见 / KP 私有 / 单个玩家私有，三种信息三处存：公开叙述、`04-KP私有.md`、`05-玩家私有/`。
- 一文件一主题，结构化字段放 YAML 或表格，叙述内容放正文。
- 剧本只声明规则系统，不写规则数值；数值一律在 `systems/` 里。

## 命名规则

| 对象 | 规则 |
| --- | --- |
| 剧本 | `scenarios/<剧本id>/`，id 用英文短名 |
| 角色 | `characters/<角色id>/角色卡.md` |
| 系统 | `systems/<系统id>/`，如 `coc7`、`dnd5e` |
| 会话 | `sessions/YYYY-MM-DD-<剧本id>-NN`，NN 自动递增 |
| 日志 | `03-日志/日志-001.md` 递增；`前情提要.md` 一份 |
