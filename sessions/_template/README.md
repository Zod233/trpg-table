# 本次跑团文件夹

复制整个文件夹 → 改名 `YYYY-MM-DD-<剧本id>-NN`（例如 `2026-11-23-rain-train-01`），或直接用 `tools/new_session.py` 生成。

| 文件 / 文件夹 | 作用 |
| --- | --- |
| `00-本次设定.md` | **manifest**：剧本、形态、规则系统与版本、人设、生成法、内容分级、参团角色、缺席处理、本团约定、装载清单 |
| `01-车卡/` | 从 `characters/` 复制的本次角色卡，成长与伤害只改这里 |
| `02-剧本/` | 从 `scenarios/` 复制的剧本副本，临时改动留在这里 |
| `03-日志/` | `日志-001.md` 递增；`前情提要.md` 是长团的滚动摘要 |
| `04-KP私有.md` | 暗投数值、真相进度、判例、即兴登记，**玩家不可见** |
| `05-玩家私有/` | 每个角色一份私密信息，只在单独行动时使用 |
| `状态跟踪.md` | 主线进度、线索、NPC、时间线、成长记录 |

## 隔离靠什么成立

1. `装载清单` 是本场唯一的上下文来源，清单外不读。
2. 剧本、角色卡都用副本，母本只读。
3. 引用走 id + 版本：`剧本id`、`角色id`、`系统版本`。
4. 开局前跑一遍 `tools/check_session.py`，机械校验清单、路径、版本、审核状态。

## 续团怎么接

装载：`前情提要.md` + `状态跟踪.md` + 最新一份日志；KP 另加载 `04-KP私有.md`。从日志的「下场开场钩子」直接接上。
