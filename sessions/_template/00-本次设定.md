## 缺席与人员流动

| 情况 | 本团处理 |
| --- | --- |
| 单场缺席 | 角色暂离，剧情中给出合理去处，回来时补一句「归队」 |
| 长期缺席（2 场以上） | 角色降为 NPC 由 KP 代管，不参与判定也不受伤害 |
| 中途加入 | 按车卡规格现场审核，通过后以「本地人 / 接到委托赶到」入场 |
| 角色死亡 | 新角色按同强度入场，或转为旁观玩家 |
| 代管 | 由同团玩家代打时，代打者只能声明行动，判定仍归 KP |
