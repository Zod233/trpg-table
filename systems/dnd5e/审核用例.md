# 审核用例（D&D 5 版）

> 修改 `车卡规格.md` 后回归：四张样例卡的结论必须与标注一致。

## 用例 A · 必过（27 点购点 + 人类）

| 项 | 值 |
| --- | --- |
| 购点分配（种族前） | STR 15、DEX 14、CON 13、WIS 12、INT 10、CHA 8 |
| 点数校验 | 9 + 7 + 5 + 4 + 2 + 0 = 27 |
| 种族加值（人类，六项各 +1） | 16 / 15 / 14 / 13 / 11 / 9 |
| 职业（战士，1 级） | HP = 10（生命骰最大值）+ 2（CON 修正）= 12 |
| 熟练加值 | +2 |
| AC | 链甲 16 + 盾牌 2 = 18 |
| 被动察觉 | 10 + 1（WIS 修正）= 11 |
| 豁免熟练 | STR、CON |
| 背景要素 | 理想 / 羁绊 / 缺点 齐全 |

**预期：通过。**

## 用例 B · 必退（数值）

## 用例 C · 必退（叙事）

| 项 | 值 |
| --- | --- |
| 数值 | 完全合规（同用例 A） |

## 用例 D · 必过（变体人类上限边界）

| 项 | 值 |
| --- | --- |
| 购点 | 15 / 14 / 13 / 12 / 10 / 8 |
| 种族 | 变体人类，+2 DEX、+1 CON |
| 结果 | DEX 17、CON 15，其余不变 |
| HP | 10 + 2 = 12 |

**预期：通过。** 15 + 2 = 17 是合法的边界值，但没有余量；若玩家随后再要「背景 +1 DEX」，即退回到 17 以上，按违例退回。
