# 车卡规格（D&D 5 版）

> KP 逐条比对，不合规即退回，只重复条目号，不辩论。

## 一、属性

| 方式 | 规则 |
| --- | --- |
| 27 点购点 | 八项属性中选六项，取值 8–15；8=0、9=1、10=2、11=3、12=4、13=5、14=7、15=9，总和 27 |
| 标准阵列 | 15 / 14 / 13 / 12 / 10 / 8 各分配一次 |

- 种族加值在购点之后加；**加值后单项上限 17**。
- 变体人类的 +2/+1 同样受 17 上限约束；标准人类 +1 六项时最高 16，不能再叠「背景加值」往上推。
- 购点 15 + 种族 +2 恰好 17 是合法的边界值，此时该项没有余量，不接受「再给自己 +1」。
- 禁止掷骰生成、禁止重排购点、禁止把种族加值算进购点预算。

## 二、派生值

| 派生值 | 规则 |
| --- | --- |
| 生命值 HP | 1 级 = 职业生命骰最大值 + CON 修正 |
| 熟练加值 | 1 级 +2 |
| AC | 护甲公式（轻甲 11+DEX、中甲 14+DEX(上限 2)、重甲固定）+ 盾牌 2 |
| 先攻 | DEX 修正 |
| 被动察觉 | 10 + 察觉修正（含熟练） |
| 豁免熟练 | 仅职业给出的两项 |

## 三、装备与法术

- 起始装备只能从职业表与背景表选取，或按规则折算金币。
- 1 级不得持有魔法物品、不得自创奇物。
- 施法者按职业表确定已知/准备法术数量与 1 级法术位。

## 四、直接退回的清单

1. 属性生成方式不明、点数对不上。
2. HP、AC、熟练加值、被动察觉与公式不符。
3. 自创种族、自创职业特性、跨职业能力、无来源的专长。
4. 加值后单项属性 ≥ 18。
5. 携带表外装备、1 级魔法物品、现代物品。
6. 角色缺少「理想 / 羁绊 / 缺点」三项背景要素。

## 五、叙事审核：同样必须退回

数值合规的卡也可能毁掉一团：

1. **预设答案**：「我在进村之前就查清了这里的一切」——把剧本真相写进背景，退回。
2. **预设关系**：自称村长之子、城主亲卫、与反派有旧交——未经剧本许可，退回或降级。
3. **万能型**：职业与背景塞进互相矛盾的多重身份（既是法师又是盗贼又是贵族）。
4. **能力越界**：1 级角色自称当过将军、统领军队、有宫廷人脉。
5. **缺少背景要素**：理想 / 羁绊 / 缺点 三项缺任一。
6. **主动敌对剧本**：背景与剧本主线直接对冲且玩家不改——不退回，提示并记入 `00-本次设定.md`。

## 六、审核输出格式

```
【审核】<角色名>
结论：通过 / 退回
不合规：第 2 条（HP 写 12，按公式应为 10）；第 4 条（DEX 加值后 18）
需修改：HP 改为 10；DEX 降 1 点并把点数退回购点池
```

审核结果写入角色卡「审核记录」并同步到 `00-本次设定.md`，未通过不得进场。

## 七、自校验用例

条文本身也会写错。修改本文件后用 `审核用例.md` 回归：三张样例卡的结论必须与标注一致，否则是条文出错，不是玩家出错。
