# 战斗与理智（D&D 5 版）

> 本框架的会话模板固定装载 `system.md` / `判定.md` / `车卡规格.md` / `战斗与理智.md` / `成长.md` 五个文件。换系统时要么提供同名文件，要么改 manifest 的装载清单。

## 一、战斗轮

1. 先攻：所有参战者掷 d20 + DEX 修正，从高到低行动；同值则 DEX 高者先，仍同则玩家方先。
2. 每轮一个动作 + 一个附赠动作 + 移动（可拆分）；反应每轮一次。
3. 攻击：d20 + 属性修正 + 熟练 vs AC。自然 20 必中且骰子翻倍；自然 1 必失。
4. 掩体：半掩体 +2 AC，四分之三掩体 +5 AC；完全掩体不能成为目标。
5. 优势/劣势：各只取一次，不叠加；两者同时存在则相互抵消。

## 二、伤害与死亡

| 情况 | 规则 |
| --- | --- |
| HP 归 0 | 陷入昏迷（unconscious），开始做死亡豁免 |
| 死亡豁免 | 每回合开始掷 d20：10 以上成功 1 次，9 以下失败 1 次；3 次成功稳定，3 次失败死亡 |
| 自然 20 | 恢复 1 HP，立即清醒 |
| 自然 1 | 计 2 次失败 |
| 受伤时已 0 HP | 每次受伤计 1 次失败；暴击计 2 次 |
| 过量伤害 | 单次伤害超过 HP 上限，直接死亡（可选规则） |
| 稳定后再受伤 | 重新开始死亡豁免 |

- **治疗**：任何治疗先让人恢复意识（有 HP 即清醒）。
- **休息**：短休 1 小时可花生命骰回复；长休 8 小时回满 HP 与一半生命骰。

## 三、常见状态（只列本框架会用到）

| 状态 | 效果 |
| --- | --- |
| 束缚 Restrained | 速度 0；攻击有劣势；DEX 豁免有劣势；对它的攻击有优势 |
| 中毒 Poisoned | 攻击与属性检定有劣势 |
| 恐慌 Frightened | 看见恐惧源时攻击与检定有劣势；不能主动靠近 |
| 目盲 Blinded | 攻击有劣势；对它的攻击有优势 |
| 俯卧 Prone | 只能爬行；近战攻击有劣势；5 尺内对它攻击有优势；起身花半速 |

## 四、环境危险

| 危险 | 规则 |
| --- | --- |
| 坠落 | 每 10 尺 1d6 钝击，落地即俯卧 |
| 火 | 接触 1d4/轮，走进火中 1d6，火墙类按法术 |
| 窒息 | 憋气 CON 修正 +1 分钟；之后每轮 CON 修正 +1 轮 |
| 黑暗 | 无光源时目盲；黑暗视觉按种族 |

## 五、与 COC 包的区别

- COC 用 d100 与成功等级，D&D 用 d20 与 DC，两套不混用。
- 本包**没有理智值**：恐惧用「恐慌」状态与叙事处理，不引入 SAN 数值。
- 死亡是「豁免三次」，不是「一次定生死」。
