# 审核用例（COC 7 版）

> 用途：修改 `车卡规格.md` 之后的回归测试。六张样例卡的结论必须与标注一致；不一致就说明条文写错了，不是玩家写错了。

## 用例 A · 必过（掷骰法）

| 项 | 值 |
| --- | --- |
| 生成方式 | 掷骰法，附六组原始骰值 |
| STR / CON / DEX / APP / POW | 50 / 55 / 55 / 45 / 50 |
| SIZ / INT / EDU | 60 / 65 / 70 |
| HP | (55+60)/10 = 11 |
| MP | 50/5 = 10 |
| SAN | 50 |
| 闪避 / 母语 | 27 / 70 |
| 职业（记者） | 职业点 EDU×4 = 280，兴趣点 INT×2 = 130，合计 410，已分配 410，单项最高 65 |
| 背景五问 | 五项齐全，无预制结论 |

**预期：通过。**

## 用例 B · 必过（快速排列）

| 项 | 值 |
| --- | --- |
| 生成方式 | 快速排列，整组分配 460 点 |
| STR / CON / SIZ / DEX / APP / INT / POW / EDU | 60 / 50 / 60 / 50 / 40 / 70 / 50 / 80 |
| HP / MP / SAN | 11 / 10 / 50 |
| 闪避 / 母语 | 25 / 80 |
| 职业（医生） | 职业点 EDU×4 = 320，兴趣点 INT×2 = 140，合计 460 |
| 背景五问 | 五项齐全 |

**预期：通过。**（注意：快速排列允许单项到 80，这正是为什么同团必须锁一种生成法）

## 用例 C · 必退（数值）

| 问题 | 具体 |
| --- | --- |
| 起始 SAN 写 60，POW 50 | 违反「起始 SAN 不得高于 POW」→ 第二条第 2 项 |
| 技能点 280 + 130 = 410，卡上分配 452 | 超预算 42 → 第三条 |
| 携带 2020 年款手枪 | 第四条第 5 项 |

**预期：退回，列出三条。**

## 用例 D · 必退（叙事）

| 项 | 值 |
| --- | --- |
| 数值 | 完全合规（同用例 A） |
| 背景「信念」 | 「这个案子我在三年前已经查清，凶手就在这列车上」 |

**预期：退回，叙事第 1 条（预设答案）。** 数值全对也挡不住这张卡毁掉一团——这条用例专门用来防止条文被改成只看数值。

## 用例 E · 必退（手法混用）

| 项 | 值 |
| --- | --- |
| 生成方式 | 掷骰法，但 SIZ 用 2d6+6 掷出 18 → 90，STR 又用快速排列的 80 |

**预期：退回，第一条第 6 项（与本团指定生成法不一致）。**

## 用例 F · 必过（职业专精突破 70）

| 项 | 值 |
| --- | --- |
| 数值 | 同用例 A，其余技能不变 |
| 侦查 | 75，卡上注明「职业：记者；规则书职业表标注该职业一项技能可至 75；KP 批准记录见 00-本次设定」 |
| 其余 | 无违例 |

**预期：通过。** 这条用例专用来防止把「70 上限」当成死的规则书原文：70 是房规，专精有来源并经批准即合法。若条文把它判退，说明条文写错了。
