# 成长（COC 7 版）

> 长团必须能成长，否则跑到第五场就没有变化。成长只在会话副本里改，不回写角色母本。

## 触发时机

每场结束、或剧本指定的幕间。

## 技能成长检定

1. 本场**用过的**技能，每个各掷一次 d100，标在日志「成长检定」栏。
2. 掷出 **> 当前技能值**，或 **96–100**，该技能 +1d10。
3. 判定失败时用过的技能也算「用过」。
4. 单项上限 90（超过 90 的技能不再成长）。

## 理智恢复（框架默认团规，剧本可覆盖）

| 方式 | 恢复 |
| --- | --- |
| 一场幕间休息 | +1d6 SAN（不超过 POW） |
| 心理治疗（需时间与金钱） | 按规则书疗程恢复 |
| 完成主线节点 | 由剧本指定，默认 +1d3 |

## 属性与生命

- 属性不成长（除非剧本明确给）。
- HP 上限不变；受伤在状态跟踪里记，幕间按规则恢复。

## 记录位置

`状态跟踪.md` 的「成长记录」表：场次 / 技能 / 原值 / 成长检定骰 / 增幅 / 新值。角色卡副本同步修改。

## 不开放的内容

- 自创法术、自学克苏鲁神话（仅剧本授予）。
- 通过扮演换取技能提升（只能用成长检定）。

## 理智奖励的溢出

结局或剧情给的理智恢复，若角色已在该场上限，超出的部分不凭空消失，按下面二选一，开团时定：

- 转为幸运，1 点理智 = 1 点幸运（推荐，纯数值，好审计）
- 记为「待用」，写进 状态跟踪 的一次性资源栏，下场的第一次理智损失时抵扣

不选就等于作废——但 KP 必须在结算时说出来，不能让玩家事后才知道白掷了。
