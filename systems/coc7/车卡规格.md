# 车卡规格（COC 7 版）

> KP 逐条比对，任何一条不合规就退回，并列出条目号与具体数值。玩家不接受审核结果时，只重复条目号，不辩论；场后可走复核（`keeper/_framework.md` 第 7 节）。

## 一、必须可溯源的生成

| 项目 | 合法范围 |
| --- | --- |
| STR / CON / DEX / APP / POW | 3d6 × 5，即 15–90，5 的倍数 |
| SIZ / INT / EDU | (2d6 + 6) × 5，即 **40–90**，5 的倍数 |
| 幸运 | 3d6 × 5 |
| 快速排列替代法 | 40 / 50 / 50 / 50 / 60 / 60 / 70 / 80 一次性分配给八项，不得只挑高项 |

- 角色卡必须写明「生成方式」与原始骰值；无法复算的数值一律退回。
- **同团必须统一生成法**：manifest 里写明本团用掷骰法还是快速排列，混用即退回——否则同桌强度不可比。
- 禁止：为高属性套年龄调整、先掷骰再按需重排（重排须整组重掷）、把职业加成混进基础属性。

## 二、派生值必须自算

| 派生值 | 公式 | 校验 |
| --- | --- | --- |
| 生命值 HP | (CON + SIZ) / 10，向下取整 | 与属性表一致 |
| 魔法 MP | POW / 5 | 同上 |
| 理智 SAN | 初始 = POW | 起始不得高于 POW |
| 伤害加值 / 体格 | 按 STR + SIZ 合计查表 | 填错即退回 |
| 闪避 | DEX / 2 | 与 DEX 一致 |
| 母语 | = EDU | 与 EDU 一致 |

## 三、技能点数

- **职业点数**：按该职业在规则书职业表里的**各自公式**计算（7 版各职业不同，常见 EDU×4、EDU×2、APP×2、DEX×2 等）。卡上必须写「职业 + 公式 + 点数」，对不上公式即退回。
- **兴趣点数**：INT × 2。
- 两点数之和必须能对上每项技能的分配，超出即退回。
- **创建期单项上限 70**：这是**本框架默认团规，不是规则书原文**。剧本可在 `00-本次设定.md` 的本团约定里放宽或收紧，改了必须写明。
- 职业专精（规则书明确给出更高值者）必须在卡上注明职业与来源，由 KP 单独批准。
- 克苏鲁神话恒为 0。

## 四、数值审核：直接退回的清单

1. 属性或技能无来源、无法复算。
2. 起始 SAN 高于 POW，或 HP / MP / 闪避 / 母语与公式不符。
3. 技能点总和超出预算。
4. 自创技能、自带超自然能力、无来源的稀有装备。
5. 携带与职业、背景、时代不符的物品（含现代枪械）。
6. 与本团指定的生成法不一致。

## 五、叙事审核：同样必须退回

数值合规的卡也可能毁掉一团，逐条看：

1. **预设答案**：「我三年前已经查清此案」「我知道凶手是谁」——把剧本的真相写进背景，直接退回。
2. **预设关系**：「我认识本地的警察局长，他会全力配合」——未经剧本许可的权威人脉，退回或降为「点头之交」。
3. **万能型**：技能铺满所有场景，或背景声称「什么都会一点」——退回，要求收窄。
4. **能力越界**：1920 年代的角色写着 2020 年代的知识与设备；平民身份写着局长、主教、军官级别的资源。
5. **背景五问留空超过两项**（信念、重要之人、意义非凡之地、宝贵之物、特质）。
6. **主动敌对剧本**：信念与剧本主线直接对冲、且玩家不打算改——不退回，但要提示并记入 `00-本次设定.md`，避免开局翻车。

## 六、审核输出格式

```
【审核】<角色名>
结论：通过 / 退回
数值不合规：第 3 条（技能点超出预算 18 点）
叙事不合规：第 1 条（背景预设了「已查清此案」）
需修改：删去预制结论，改为「三年前经手过类似案件，但没查到底」
```

审核结果写进角色卡「审核记录」并同步 `00-本次设定.md`。未通过不得进场。

## 七、自校验用例

条文本身也会写错。每次修改本文件后，用 `审核用例.md` 里的样例卡回归：四张样例卡（两张必过、两张必退）结论必须与标注一致，否则是条文出错，不是玩家出错。
