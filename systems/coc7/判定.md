# 判定（COC 7 版）

## 掷骰权

骰值由 KP 掷出，或由玩家用 `tools/roll.py` 等可验证工具掷后把输出贴进对话；只报数字无效。明投公布骰值，暗投只写进 `04-KP私有.md`。同一次判定掷一次即定。

## 基本判定

掷 d100，骰值 ≤ 技能值为成功。KP 只判成功等级，不重复判难度。

| 骰值 | 成功等级 | 结果 |
| --- | --- | --- |
| 01–05 | 大成功 | 达成目的并有额外收益 |
| ≤ 技能/5 | 极难成功 | 出色完成，不留痕迹 |
| ≤ 技能/2 | 困难成功 | 干净利落 |
| ≤ 技能 | 常规成功 | 达成目的 |
| > 技能 | 失败 | 未达成 |
| 96–100 | 大失败 | 仅当技能 < 50 时成立 |

## 难度设定（KP 一次定死）

| 难度 | 要求 | 何时用 |
| --- | --- | --- |
| 常规 | 常规成功 | 默认 |
| 困难 | 困难成功 | 条件差、时间紧、有干扰 |
| 极难 | 极难成功 | 近乎不可能、缺少工具 |
| 无需掷骰 | 直接成功 | 日常、无风险、有条理有工具 |

难度在掷骰前公布（暗投除外），公布后不改。

## 奖励骰与惩罚骰

多掷一颗十位骰，取更有利（奖励）或更不利（惩罚）的一颗。

- 奖励骰来源：准备充分、工具齐备、时间充裕、玩家给出的具体可行做法。
- 惩罚骰来源：受伤、黑暗、被监视、仓促、缺工具。
- 上限：单次最多两颗奖励骰或两颗惩罚骰，奖惩相抵后结算。

## 孤注一掷

失败后可声明「更用力地再来一次」，获得一次重掷；同一技能同一目标只能一次。再失败，代价升级：受伤、暴露、毁掉线索、时间被拖到不可挽回。

## 幸运点（可花，不是 KP 的恩赐）

幸运是玩家可支配的资源，不是摆设。

- **提前压低骰值**：掷骰前或掷骰后**当场**声明，花 1 点幸运把骰值降 1，直到降到想要的成功等级为止。骰值降到 01 即止。
- **判完封口**：一旦结算完、进入下一段叙事，就不能回头改判。所以 KP 必须在玩家掷骰前明确提示「可以花幸运」，不提示即视为放弃本条的可用性——这是 KP 的义务，不是玩家的。
- **幸运不回补**：一场内花完就是花完；场末按 `成长.md` 的规则回补（若有）。
- **不能买成功等级**：幸运只能压骰值，不能把失败改成大成功，也不能改别人的骰。

## 突袭与先攻

- 先攻按 DEX 从高到低；DEX 相同则比技能值。
- **突袭成立的条件**：目标尚未察觉攻击者存在。判定用潜行（或隐蔽）对抗目标的聆听/侦查。
- 突袭成功：突袭方获得本轮先手，且第一次攻击 **+1 颗奖励骰**。
- 突袭失败：对方照常行动；若对方本就在等待你（例如它已知你会回来），**不成立突袭**，别硬套。

## 对抗判定

双方各掷，成功等级高者胜；同级比技能值高者胜；再相同则维持原状，双方都未达成目的。

## 集团判定

多人协作时由主导者掷，其他人提供奖励骰；不做逐人累加。

## 不掷骰的情形

- 玩家已给出足够好的扮演与合理解法，且无风险。
- 结果不可能改变（无论成败都不影响任何事）。
- 重复同一动作、同一目标，已判定过。
