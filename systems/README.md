# 规则系统包

一套规则一个文件夹：`systems/coc7/`、`systems/dnd5e/`，或按 `_template/` 自己加。

必备三件：

| 文件 | 作用 |
| --- | --- |
| `system.md` | 元信息（id、版本）、适用题材、核心机制、默认团规 |
| `车卡规格.md` | 合法与非法、审核清单、退回条目、审核输出格式 |
| `判定.md` | 判定方式、难度阶梯、优劣、对抗、明暗投、不掷骰的情形 |

可选专题文件，如 `战斗与理智.md`。

新增系统：复制 `_template/` → 改名为系统 id → 填满三件 → 在剧本 `00-剧本概览.md` 声明 `规则系统: <id>`。

规则包只加版本号、不改旧内容（`版本: 1.1`）；会话 manifest 锁版本，老会话不受影响。
