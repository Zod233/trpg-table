# 剧本骨架

复制整个文件夹，改名为剧本名，例如 `scenarios/雨夜列车/`，再逐个填。

| 文件 | 内容 |
| --- | --- |
| `00-剧本概览.md` | 元数据、一句话简介、开团前可公开的信息、KP 必读、线索总表 |
| `01-背景与真相.md` | 表层事件、真实真相、时间线、势力与动机、掌控要点 |
| `02-登场人物.md` | NPC 动机、秘密、说话方式、扮演提示 |
| `03-线索与调查点.md` | 每个地点可查什么、怎么查、失败也拿得到的保底线索 |
| `04-关键场景.md` | 必须出现的那几幕：目的、氛围、判定、分支 |
| `05-结局分支.md` | 结局达成条件与收尾写法 |

母本只读：跑团时把整份复制到 `sessions/<本次>/02-剧本/`，改动留在副本里。
